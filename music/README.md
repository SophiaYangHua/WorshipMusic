# 音乐目录

把歌曲放进这里即可，**每首歌一个文件夹，文件夹名就是歌曲名**，例如：

```
music/
└── 奇异恩典/
    ├── 奇异恩典.mp3          # 原唱（必需）
    ├── 奇异恩典[伴奏].mp3    # 伴奏（可选）
    └── 奇异恩典.jpg          # 歌谱（可选）
```

## 命名规则

| 文件 | 要求 |
| --- | --- |
| 原唱 | `.mp3` 结尾，不带 `[伴奏]` 标记的 mp3 |
| 伴奏 | 文件名中带 `[伴奏]` 标记，例如 `奇异恩典[伴奏].mp3` |
| 歌谱 | 支持 `.jpg` / `.jpeg` / `.png` / `.webp` |

> 建议原唱文件名与文件夹名保持一致，便于识别。

## 怎么上传

1. 打开 https://github.com/SophiaYangHua/WorshipMusic
2. 进入 `music` 目录 → 点右上角 **Add file** → **Upload files**
3. 先把文件夹拖进去（GitHub 网页支持拖拽整个文件夹），或先在本地建好 `歌曲名/歌曲名.mp3` 再整体拖入
4. 点击 **Commit changes**

提交后 Cloudflare Pages 会自动重新部署，稍等 1～2 分钟刷新网站即可看到新歌，**不需要改任何代码**。
